# Восстановление + Обучение C++

Этот репозиторий создан как личное пространство для восстановления от выгорания при изучении программирования и углубления практических навыков C++.

## Основные идеи и принципы

- **С самого нуля**: Все проекты пишутся полностью самостоятельно. Никаких готовых шаблонов, копирования кода или сторонних фреймворков на начальных этапах. Только собственный код, собственные архитектурные решения и глубокое понимание каждой строчки.
- **Борьба с выгоранием**: Спокойное написание проектов в комфортном темпе, регулярная фиксация прогресса через осмысленные коммиты, создание работающих и интересных программ для души.
- **Текущий уровень и цели**: Текущий уровень оценивается как Junior. Основная цель — планомерное развитие до уровня Middle.
- **Долгосрочное обязательство**: Этот репозиторий развивается на постоянной основе и никогда не будет заброшен.

## Текущий проект: Графический RPG Квест (Legends of Green Meadow)

Ролевая игра с графическим интерфейсом на базе библиотеки **Raylib**. Игрок создает уникального персонажа, выбирает класс, исследует живописные локации, собирает ресурсы и участвует в случайных встречах и пошаговых битвах.

### Пошаговый план разработки

1. **Шаг 1: Ядро и Игрок** [ВЫПОЛНЕНО]
   - Базовая структура `Player` (имя, здоровье, урон, золото).
   - Простой текстовый цикл ввода-вывода.
2. **Шаг 2: Система локаций и биомы** [ВЫПОЛНЕНО]
   - Перемещение между безопасным лагерем и биомом «Зеленая Поляна».
   - Интерактивное окружение (осмотр местности, сбор лечебных трав, поиск золотых цветов).
   - Случайная встреча со Слизью (уникальная механика приручения с 80% шансом успеха и 20% риском гибели, либо стандартный бой).
3. **Шаг 3: Переход на графический интерфейс (GUI)** [ВЫПОЛНЕНО]
   - Полная интеграция с графической библиотекой **Raylib 5.0**.
   - Реализация конечного автомата состояний (`GameState`) для неблокирующих переходов между сценами.
   - Разработка темного игрового интерфейса:
     - Экран создания персонажа с поддержкой ввода кириллицы.
     - Экран выбора класса с интерактивными визуальными карточками.
     - Информационная панель героя с анимированной полосой здоровья (HP).
     - Разделенный экран: панель действий и прокручиваемый журнал событий с цветовым выделением и эффектом плавного затухания текста.
     - Экран поражения с возможностью мгновенного перезапуска.
4. **Шаг 4: Предметы и Инвентарь** [ВЫПОЛНЕНО]
   - Реализация структуры предметов (`ItemType`) и инвентаря игрока.
   - Сбор трав в инвентарь на карте.
   - Полноценное окно инвентаря для просмотра и использования собранных трав.
5. **Шаг 5: Враги и пошаговая боевая система** [В ПРОЦЕССЕ]
   - Добавление блуждающих слизней на карту.
   - Полноценная боевая сцена в GUI (атака, побег, попытка приручить).
   - *В планах:* разнообразие врагов и использование инвентаря в бою.
6. **Шаг 6: Сохранение и загрузка прогресса** [В ПЛАНАХ]
   - Сериализация состояния игрока и мира в файл `save.txt` и автозагрузка при старте.

## Инструкция по запуску

### Требования к огружению
- **ОС**: Windows 10/11
- **Компилятор**: `g++` (MinGW-w64), путь к которому добавлен в системную переменную `PATH`.
- **Интерпретатор**: PowerShell (для запуска скриптов автоматизации).

### Сборка и запуск
1. **Загрузка зависимостей**:
   Скрипт автоматически скачает и распакует нужную версию Raylib 5.0 в директорию `raylib_dep`:
   ```powershell
   .\download_raylib.ps1
   ```
2. **Компиляция**:
   Соберите исполняемый файл с помощью скрипта сборки:
   ```powershell
   .\compile.ps1
   ```
3. **Запуск игры**:
   Запустите скомпилированную игру:
   ```powershell
   .\main.exe
   ```
