# Legends of Green Meadow - 2D RPG Survival

Моя 2D RPG в стиле аниме-фэнтези на C++ с Raylib 5.0. Вдохновлена базовыми механиками Minecraft и духом Legends of Green Meadow.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Передвижение |
| E | Добыча ресурсов, отдых в палатке, фермерство |
| F | Рыбалка (у воды) |
| T | Торговля (рядом с торговцем) |
| R | Полить грядку |
| I / TAB | Открыть/закрыть инвентарь |
| C | Открыть/закрыть крафт |
| F11 | Полноэкранный режим |
| ESC | Закрыть меню |
| ENTER | Подтвердить |

## Классы персонажей

| Класс | HP | Урон | Особенность |
|-------|----|----|-------------|
| Воин | 120 | 10 | Выносливость, меньше урона от слизней |
| Маг | 80 | 20 | Критический урон (30% шанс x1.5), магические частицы |

## Системы выживания

### Здоровье и Голод
- **HP** — отображается сердечками в стиле Minecraft (10 сердец = 20 HP)
- **Голод** — отображается шампуриками (10 шампуриков = 20 голода)
- Голод убывает каждые 30 секунд
- При нулевом голоде HP падает
- При голоде > 10 HP регенерируется

### Опыт и Уровни
- Получайте XP за добычу ресурсов (+10), убийство слизней (+25), рыбалку (+15)
- Каждый уровень даёт +2 очка навыков
- Автоматическое увеличение HP и урона с уровнем

### Погода
- **Ясно** — обычная скорость
- **Дождь** — скорость -15%, видны капли дождя
- **Снег** — скорость -30%, снежинки
- **Туман** — скорость -5%, ограниченная видимость

## Добыча ресурсов

- **Дерево** (E рядом с деревом) — деревья с HP, при ударе дрожат, исчезают при 0 HP, выпадает 2-4 дерева
- **Камень** (E рядом с камнем) — камни с HP, при ударе дрожат, исчезают при 0 HP, выпадает 2-3 камня
- **Трава** — автоматический сбор при приближении
- **Золотоцвет** — автоматический сбор, даёт золото
- **Руда железа** — нужна каменная кирка или лучше
- **Руда алмаза** — нужна железная кирка

## Фермерство

1. Скрафтите семена из урожая (пшеница → 3 семени)
2. Подойдите к грядке рядом с лагерем
3. Нажмите **E** чтобы посадить
4. Нажмите **R** чтобы полить (ускоряет рост в 1.5 раза)
5. Подождите пока вырастет (3 стадии по 30 секунд)
6. Нажмите **E** чтобы собрать урожай

## Рыбалка

1. Подойдите к озеру
2. Нажмите **F** чтобы забросить удочку
3. Ждите поклёвки (3-7 секунд)
4. Когда рыба клюёт — быстро нажмите **F** (1.5 секунды на подсечку)
5. Получите рыбу +15 XP

## Торговля

Рядом с торговцем (рядом с лагерем) нажмите **T**:
- 40 золота → Зелье HP (лечит 50 HP)

## Игровой мир

### Биомы (5 штук)
- **Лес** — зелёный, стандартные деревья, много травы
- **Пустыня** — песчаный, сухие деревья, мало растительности
- **Снег** — белый, заснеженные деревья, холод
- **Болото** — тёмный, мрачные деревья, туман
- **Луга** — яркий, цветочные деревья, много цветов

### Объекты мира
- Лагерь с палаткой (отдых [E]) и костром
- Озеро с анимацией волн и бликами
- 40 деревьев (с HP и респавном)
- 8 камней (с HP и респавном)
- 7 слизней (зелёные, красные, синие)
- Волки (появляются с 3 дня)
- Скелеты (ночные враги, с 2 дня)
- Торговец (рядом с лагерем)
- Фермерские грядки (рядом с лагерем)
- Рыбацкие точки (у озера)

### Враги
| Враг | HP | Урон | Особенность |
|------|----|----|-------------|
| Зелёная слизь | 25-40 | 6-12 | Обычная |
| Красная слизь | 30-45 | 8-14 | Быстрая |
| Синяя слизь | 35-50 | 10-16 | Крепкая |
| Волк | 40+ | 8 | Агрессивный, преследует |
| Скелет | 50+ | 12 | Ночной, сильный |
