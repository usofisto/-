# Legends of Green Meadow

Ролевая игра с открытым миром на базе **Raylib 5.0**. Исследуй лес, собирай ресурсы, крафти инструменты, сражайся со слизнями.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Перемещение |
| E | Добыча ресурсов / Отдых в палатке |
| I / TAB | Инвентарь |
| C | Крафт |
| F11 | Полноэкранный режим |
| ESC | Закрыть меню |

## Механики

### Выживание
- **Здоровье (HP)** — уменьшается при ударах врагов и от голода. Восстанавливается травой или отдыхом.
- **Голод** — убывает каждые 30 секунд. При нулевом голоде теряешь HP. Хлеб восстанавливает голод.

### Добыча ресурсов
- **[E] рядом с деревом** — 1-2 дерева
- **[E] рядом с валуном** — 1-2 камня
- **Сбор трав** — проходи рядом для автоматического сбора
- **Золотоцвет** — даёт золото

### Крафт (клавиша C)
| Рецепт | Ингредиенты | Результат |
|--------|-------------|-----------|
| Доски | 1 дерево | 4 доски |
| Палка | 2 доски | 4 палки |
| Деревянная кирка | 3 доски + 2 палки | 1 кирка |
| Деревянный меч | 2 доски + 1 палка | 1 меч |
| Деревянный топор | 2 доски + 1 палка | 1 топор |
| Каменная кирка | 3 камня + 2 палки | 1 кирка |
| Каменный меч | 2 камня + 1 палка | 1 меч |

### День/ночь
Мир имеет цикл день/ночь: Утро → День → Вечер → Ночь. Вечером и ночью затемняется экран.

### Боевая система
Пошаговый бой: Атака / Приручение / Побег. Слизни блуждают по карте и атакуют при столкновении.

## Классы персонажей

| Класс | HP | Урон | Особенность |
|-------|-----|------|-------------|
| Воин | 120 | 10 | Снижение урона врагов |
| Маг | 80 | 20 | 30% шанс крита |
| Лучник | 100 | 15 | Сбалансированный |

## Сборка и запуск

### Требования
- Windows 10/11
- g++ (MinGW-w64) в PATH
- PowerShell

### Компиляция
```powershell
.\compile.ps1
```

### Запуск
```powershell
.\main.exe
```
