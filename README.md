# Legends of Green Meadow - 2D RPG

Моя 2D RPG в стиле аниме-фэнтези на C++ с Raylib 5.0. Вдохновлена базовыми механиками Minecraft и духом Legends of Green Meadow.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD / Стрелки | Передвижение |
| E | Добыча ресурсов (дерево, камень), отдых в палатке |
| I / TAB | Открыть/закрыть инвентарь |
| C | Открыть/закрыть крафт |
| F11 | Полноэкранный режим |
| ESC | Закрыть меню |
| ENTER | Подтвердить |

## Классы персонажей

| Класс | HP | Урон | Особенность |
|-------|----|----|-------------|
| Воин | 120 | 10 | Выносливость, меньше урона от слизней |
| Маг | 80 | 20 | Критический урон (30% шанс x1.5), магические частицы |
| Лучник | 100 | 15 | Сбалансированный |

## Механики выживания

- **Здоровье (HP)** — отображается сердечками в стиле Minecraft (10 сердец = 20 HP)
- **Голод** — отображается шампуриками (10 шампуриков = 20 голода)
- Голод убывает каждые 30 секунд
- При нулевом голоде HP падает
- При голоде > 10 HP регенерируется
- День/ночь цикл: утро, день, вечер, ночь

## Добыча ресурсов

- **Дерево** (E рядом с деревом) — деревья с HP, при ударе дрожат, исчезают при 0 HP, выпадает 2-4 дерева
- **Камень** (E рядом с камнем) — камни с HP, при ударе дрожат, исчезают при 0 HP, выпадает 2-3 камня
- **Трава** — автоматический сбор при приближении
- **Золотоцвет** — автоматический сбор, даёт золото

## Крафт

| Результат | Ингредиенты |
|-----------|-------------|
| Доски (x4) | Дерево x1 |
| Палки (x4) | Доски x2 |
| Деревянная кирка | Доски x3, Палки x2 |
| Деревянный меч | Доски x2, Палки x1 |
| Деревянный топор | Доски x3, Палки x2 |
| Каменная кирка | Камень x3, Палки x2 |
| Каменный меч | Камень x2, Палки x1 |
| Каменный топор | Камень x2, Палки x1 |
| Хлеб (x3) | Леч. трава x2, Золотоцвет x1 |
| Факел (x2) | Палка x1, Дерево x1 |

## Игровой мир

- Лагерь с палаткой (отдых [E]) и костром (анимация 4 кадра PNG)
- Озеро с анимацией волн и бликами
- 40 деревьев (с HP и респавном)
- 8 камней (с HP и респавном)
- 7 слизней (зелёные и быстрые алые)
- Руины каменных стен
- День/ночь цикл с оверлеем на весь экран

## Графика

- 10 уникальных PNG текстур деревьев (дуб, сосна, берёза, клён, ива, вишня, мёртвое, яблоня, пальма, ель)
- 10 уникальных чанков травы (цветы, грибы, одуванчики, мух, клевер, камни, ягоды, листья, бабочки)
- 5 видов камней (серый, песчаник, обсидиан, известняк, гранит)
- 3 вида слизней (зелёная, красная, синяя) с уникальными текстурами
- Озеро с текстурой воды и волнами
- Анимация костра (4 кадра PNG)
- Свечение костра ночью
- Анимация взмаха оружием при добыче
- Дрожание деревьев и камней при ударе
- Частицы пыли при ходьбе
- Звёзды ночью (мерцающие)
- Полноэкранный режим (F11)
- Мини-карта мира
