# Восстановление + Обучение C++

## Описание проекта

Этот проект создан как средство восстановления от выгорания при учебе программированию. Основная идея: **потихоньку писать проекты с нуля**, чтобы:

- Очистить голову от стресса и перегрузки
- Постепенно углубить знания C++ на практике
- Регулярно фиксировать прогресс через коммиты
- Создавать что-то осмысленное и работающее

## С самого нуля

Все проекты в этом репозитории пишутся **полностью с нуля**. Никаких готовых шаблонов, никаких копипастов, никаких фреймворков в начале. Только собственный код, собственные решения и собственное понимание.

Это означает:
- Реальное восстановление навыков и уверенности

## Текущий уровень и цели

**Текущий уровень**: Новичок / примерно Junior

**Цель**: Достичь уровня Middle разработчика

**Обязательство**: Этот репозиторий **никогда не будет заброшен**. Активное развитие продолжается постоянно. Перерывы предусмотрены только в дни отдыха.

## График коммитов

- **Основной ритм**: еженедельные коммиты
- **Альтернативный вариант**: ежедневные коммиты перед сном
- Каждый коммит = завершенный микропроект или значительный прогресс

## Принцип работы

1. Выбираем одну небольшую задачу
2. Пишем решение с нуля
3. Тестируем
4. Коммитим с описанием

**Никакого спешки** — качество > количество

## Правила кодирования и комментирования
- **Комментарии в коде**: Для дальнейшей реализации обязательно использовать подробные комментарии и структурированные блоки описания для всех ключевых функций, структур и разветвлений логики. Это необходимо для простоты восстановления контекста и обучения.

## Текущий проект: Текстовый RPG Квест (Text RPG Quest)

**Идея**: Консольная текстовая игра, в которой игрок исследует локации, взаимодействует с окружением, управляет инвентарем и сражается с врагами.

### План разработки по шагам:
1. **Шаг 1: Ядро и Игрок** [ВЫПОЛНЕНО]
   - Создание структуры `Player` (имя, здоровье, урон, золото).
   - Базовый цикл ввода-вывода (обработка текстовых команд: `status`, `help`, `exit`).
2. **Шаг 2: Система локаций (Карта)** [В ПРОЦЕССЕ]
   - Структура `Room` / концепция свободных Биомов.
   - Перемещение игрока между локациями (выбор переходов в главном меню).
   - Первый биом «Зеленая Поляна» с интерактивным окружением (травы, цветы) и случайными встречами.
3. **Шаг 3: Предметы и Инвентарь**
   - Структура `Item` (название, описание, эффект).
   - Инвентарь игрока (`std::vector<Item>`).
   - Команды: `take <предмет>`, `inventory`, `use <предмет>`.
4. **Шаг 4: Враги и Боевая система**
   - Структура `Enemy` (имя, здоровье, урон).
   - Пошаговый бой (команды `attack`, `run`, `use <зелье>`).
5. **Шаг 5: Сохранение и загрузка**
   - Запись состояния игрока и комнат в файл (`save.txt`) и чтение из него.
